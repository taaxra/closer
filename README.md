# Closer

A question game that gets your group past small talk. 294 questions in three levels (Warm-up, Personal, Deep).

## Put it online with GitHub Pages
1. Upload all files in this folder to the root of a GitHub repository.
2. In the repository: Settings > Pages > "Deploy from a branch" > Branch `main`, folder `/ (root)` > Save.
3. After 1-2 minutes the app is live at `https://<your-username>.github.io/<repository-name>/`.

## Updating
Replace `index.html` and change `VERSION` in `sw.js` (for example `closer-v2`) so phones pick up the new version.
